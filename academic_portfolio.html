ขั้นตอนง่ายๆ ในการสร้างเว็บไซต์ออนไลน์ส่วนตัวฟรี

1

สร้าง Repository

เข้า GitHub.com แล้วสร้าง Repository ใหม่ ตั้งชื่อเป็น portfolio และตั้งเป็น Public

2

อัปโหลดไฟล์

บันทึกโค้ดหน้านี้เป็นชื่อ index.html จากนั้นกด Upload files เข้าไปที่ Root directory แล้วกด Commit

3

เปิดใช้งาน Pages

ไปที่ Settings > Pages เลือก Source เป็น Branch main / root แล้วกด Save รอ 1-2 นาทีจะเปิดดูเว็บได้ทันที!
